# remplanner-skills: правила для правки набора

Это репозиторий самих скилов, а не проект квартиры. Пишем по-русски: аудитория — владельцы квартир в РФ и СНГ.

## Устройство

- `skills/<name>/SKILL.md` — один скил в папке; справочные файлы скила лежат рядом с его `SKILL.md`.
- Скил либо вызывает пользователь (`disable-model-invocation: true`, `description` — одна строка для человека),
  либо агент (без этого поля, `description` с фразами-триггерами «Используй, когда…»). Скил, вызываемый
  пользователем, может вызвать скил агента, но не другой пользовательский: в таком месте пишем
  «скажи пользователю набрать `/имя`».
- Зависимость между скилами — явная инструкция: «вызови Skill tool с `check-plan`», а не ссылка
  на файл чужой папки. Один вызов — один скил.
- Python-инструменты живут в `skills/setup-remplanner-skills/toolkit/`; setup копирует их в `tools/` проекта
  квартиры. Остальные скилы обращаются к `tools/` проекта, а не к папке плагина.
- Каждый скил — в `.claude-plugin/plugin.json` (`skills`) и в таблице README; `ask-planner` — карта всех
  пользовательских скилов: добавил, переименовал или поменял место скила во флоу — поправь `ask-planner`.
- После правки манифестов: `claude plugin validate . --strict`.

## Содержимое

- Никаких данных конкретной квартиры и жильцов: адресов, планов, требований. Пример — только обезличенная
  типовая планировка в `examples/`.
- Каталог RemPlanner (`remplanner_catalog.json`) не коммитим: он собирается у пользователя из публичного JS.
- Каждый норматив и размер — с источником или пометкой «предположение».
- Инструменты — Python 3.10+ без сторонних пакетов.

## Проверка инструментов

`python3 skills/setup-remplanner-skills/toolkit/selftest.py` — экспорт и проверки на примере из `examples/`.
