# Снимки RemPlanner

Картинки планов — только снимки самого RemPlanner: снимок вкладки «Перегородки» после импорта и есть проверка,
что импорт удался. Нужно расширение Claude in Chrome. Его нет или оно не отвечает после двух попыток —
скажи пользователю и отдай файлы `.plan`, чтобы он открыл их сам.

Пошаговый рецепт с координатами, ловушками интерфейса и признаками сбоя импорта —
`tools/reference/REMPLANNER_UI.md` «Снимки серии». Прочитай его перед первым снимком в сессии.

## Порядок

1. Список: какие `.plan` снимать и имя снимка для каждого — `screenshots/run-NN_<name>.png`
   (`screenshots/as_is.png` для плана «как есть»). Все снимки — в одной папке, чтобы листать подряд.
2. Предупреди пользователя один раз: импорт заменяет проект, открытый в RemPlanner в этом браузере.
3. Открой новую вкладку https://remplanner.ru/planner/, найди поле загрузки `.plan` и вкладку «Перегородки»
   (по рецепту).
4. **Один план на пакет браузера:** загрузить файл → снять заставку → «Перегородки» → снимок области плана
   с сохранением на диск → сразу `python3 tools/save_shots.py screenshots/<имя>.png`. Длинные пакеты обрывают
   связь с расширением, а один план на пакет не путает порядок снимков.
5. Посмотри на каждый снимок: активна не та вкладка, видна заставка, нет мебели — переснять этот план.
6. Закрой вкладку. Если в окружении есть отправка файлов пользователю — отправь снимки.

Готово, когда для каждого плана из списка есть снимок в `screenshots/` и на нём вкладка «Перегородки»
с мебелью.

Новый приём или ловушка интерфейса — допиши в `tools/reference/REMPLANNER_UI.md` и скажи пользователю:
этот файл перезаписывается при обновлении, приём стоит отправить в репозиторий набора.
