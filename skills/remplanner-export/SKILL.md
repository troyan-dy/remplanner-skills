# Выгрузка в RemPlanner

```bash
python3 tools/remplanner_export.py <json…>   # без аргументов — plan/*.json и concepts/*/*.json
```

Пишет `<name>.plan` рядом с каждым JSON и печатает число стен, проёмов и предметов. `.plan` только генерируется:
правка — в генераторе (`src/…`), затем выгрузка заново.

- Предмет выгружается, только если у него есть `rp` с именем из каталога. Предмет без `rp` молча пропадает
  из RemPlanner — сверь число предметов в выводе с планом.
- Ошибка про стену или перегородку (не примыкает, пересекает несущую) — исправь геометрию в генераторе.
- Нужен тип предмета, проёма или поле, которых экспортёр не знает, — скажи пользователю набрать
  `/remplanner-primitive`.

Как открыть у себя (скажи это пользователю, если он открывает сам): RemPlanner → «Скачать/загрузить файл» →
«Загрузить файл .plan». **Импорт заменяет текущий проект в браузере** — свой проект сначала сохранить.

Формат JSON — `tools/reference/PLAN_FORMAT.md`; формат `.plan` и что проверено импортом —
`tools/reference/REMPLANNER_V3_SCHEMA.md` (нужен только при правке экспортёра).
