# Каталог RemPlanner

```bash
python3 tools/rp_catalog.py find <слово> [<слово> …]   # поиск по имени, названию, разделу
python3 tools/rp_catalog.py show <name>                # всё о предмете: габарит, высота, подводки, группа
```

Нет каталога (`tools/catalog/remplanner_catalog.json`) — `python3 tools/rp_catalog.py fetch` (качает публичный
файл инструментов RemPlanner и собирает каталог).

Поиск — по подстроке названия и английского имени. Русские словоформы не склоняются: ищи коротким корнем
(«кош», «корм», «пенал») или по-английски (`litter`, `feeder`, `penal`). Чего-то нет (детская кроватка, индукция
отдельно) — ближайший предмет по габариту с пометкой в `name` предмета и в README серии.

## Как подбирать

1. Под зону, а не по привычке: для каждой зоны ищи по нескольким словам (тумба, пенал, навесн, угловой, узк…)
   и выбирай под задачу и правила пользователя.
2. `show <name>` перед тем как ставить: габарит каталога — исходный, на плане предмет можно растянуть, но
   правило группы (в выводе `show`) говорит, что допустимо: проходы, высота, к какой стене спинкой.
3. В плане — `rp: {"name": <name>, "back": "up|down|left|right"}`; `back` — куда обращена спинка, бачок или
   изголовье. Навесное — с `over_floor` (высота низа, см). Кухонная линия — `kitchen_run` с модулями
   (`tools/reference/PLAN_FORMAT.md`).
4. Предмет, которого нет среди проверенных импортом (`rp_lib.CATALOG` и `tools/catalog/confirmed.json`),
   впервые попадает в RemPlanner — проверь на снимке, что он на месте и развёрнут как надо. Подтвердился —
   добавь его имя с датой в `tools/catalog/confirmed.json` (папку `catalog/` setup не перезаписывает).

Справочник `tools/catalog/REMPLANNER_CATALOG.md` большой: ищи в нём по месту, целиком не читай.
