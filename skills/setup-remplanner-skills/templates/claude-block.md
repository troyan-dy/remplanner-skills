## Планировка

Проект квартиры для скилов remplanner-skills. Результат — файлы RemPlanner `.plan`, сгенерированные из JSON;
`.plan` только генерировать (`python3 tools/remplanner_export.py`), руками не править.

### Файлы

- `REQUIREMENTS.md` — жильцы, правила расстановки п. N, открытые вопросы. Личные данные: остаются в этой папке.
- `rules.json` — проверяемые правила для `tools/check_rules.py` (типы — `tools/reference/RULES.md`).
- `plan/source/` — план БТИ, экспликация, замеры; `plan/as_is.json` — квартира «как есть», строится
  `src/as_is.py`.
- `src/concepts_runNN.py` — генератор серии; `concepts/run-NN_<ГГГГ-ММ-ДД>/` — `<name>.json`, `<name>.plan`,
  `README.md` серии. Прошлые серии не правим, блоки из них импортируем.
- `screenshots/` — снимки RemPlanner всех серий подряд: `run-NN_<name>.png`, `as_is.png`.
- `tools/` — инструменты набора (обновляет `/setup-remplanner-skills`, руками не править). Формат плана —
  `tools/reference/PLAN_FORMAT.md`, эргономика — `tools/reference/ERGONOMICS.md`.

### Правила

- Несущее (`walls_bearing`: фасад, межквартирные, внутренние несущие, колонны) и ригели неприкосновенны:
  не двигать, не сносить, не прорезать. Менять можно `partitions`, `doors`, `furniture`, `zones`, `rooms`.
- Мокрые зоны (санузел, кухня, стирка) — только там, где их разрешают стояки и правила дома: смотри
  `REQUIREMENTS.md` «Исходные данные и ограничения».
- Перед сантехникой — `zones`: унитаз ≥ 60, раковина ≥ 70, вход в душ ≥ 70; коридор ≥ 85.
- Каждый новый размер, норматив или юридическое утверждение — с источником, иначе с пометкой «предположение».
- Каждая концепция проходит `tools/check_layout.py`, `tools/check_rules.py`; уступки от «желательно» —
  в `ergo_waivers` с обоснованием «что выигрываем».
